## 📋 Descripción del proyecto

Este repositorio contiene una **landing page one-page, mobile-first, responsiva y accesible** que funciona como CV digital y portafolio de Ally Villagómez, junto con su **Design System completo** documentado.

### Landing page (`index.html`)
- **Hero**: nombre, tagline profesional, 2 CTAs (Ver portafolio / Contáctame), foto de perfil
- **Sobre mí**: presentación en primera persona, intereses en identidad visual, branding, campañas
- **Portafolio**: 4 proyectos reales (Pedro, Dravy, Aerolínea, Santa Clara) con tarjetas y modales accesibles
- **Proceso de diseño**: 4 etapas (investigación → conceptualización → desarrollo visual → refinamiento)
- **Habilidades y herramientas**: áreas de especialización (chips) + software manejado (Illustrator, After Effects, Maya, Substance Painter, ZBrush, Canva, CapCut, Figma)
- **Formación**: estudios en Diseño Gráfico
- **Contacto**: botón mailto + íconos sociales (GitHub, LinkedIn, Instagram) 32×32px
- **Footer**: nombre, tagline, navegación secundaria, estrellas decorativas

### Design System (`design.html` + `DESIGN.md`)
- **Colors**: 13 tokens (primario, secundario, neutros, estados)
- **Typography**: 2 familias (Hobeaux Bold / Avenir), jerarquía completa, 12 tokens
- **Layout**: spacing base 8px, grid 12/8/1 col, whitespace principles
- **Elevation & Depth**: sombras sutiles, 2 niveles
- **Shapes**: 5 radios (8–9999px), formas geométricas/orgánicas
- **Components**: Button (3 variantes), Card, Input, Link, Social Icon, Star
- **Do's and Don'ts**: 10 reglas cada uno con ejemplos visuales

### Tecnologías
- **HTML semántico**, **CSS vanilla** (custom properties derivadas de tokens), **JavaScript vanilla** (mínimo: nav hamburguesa, modales con focus trap, smooth scroll)
- **Fuentes locales**: BreeSerif (fallback Hobeaux Bold), NunitoSans variable (fallback Avenir)
- **Accesibilidad WCAG AA**: contraste, foco visible, landmarks, ARIA, skip link
- **Responsive**: mobile-first, breakpoints 768px / 1024px
